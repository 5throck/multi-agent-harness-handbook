# Multi-Agent Harness Engineering Handbook

Language: [English](README.md) | [한국어](README_ko.md) | [日本語](README_ja.md) | [Español](README_es.md)

Welcome to the **Multi-Agent Harness Engineering Handbook**, an AI Workspace educational program. This program guides developers and engineering teams through harness engineering concepts, multi-agent workflows, tool integrations (Claude Code, Claude Desktop App, Antigravity CLI, Antigravity Desktop), enterprise operating strategies, and hands-on exercises for creating customized workspace variants with `ai-workspace-standards`.

## 🌐 Read the Handbook Live
👉 **[Online Handbook & Educational Program](https://5throck.github.io/multi-agent-harness-handbook/)**

> **Note:** The core online handbook site is primarily provided in Korean with multi-language navigation. Language-specific README files help guide global participants and contributors.

## 💻 Local Setup
The workshop install scripts live in a separate repository, [5throck/setup](https://github.com/5throck/setup) — clone it directly rather than vendoring a copy here:
```bash
git clone https://github.com/5throck/setup.git
cd setup
```
See the [Setup Guide](https://5throck.github.io/multi-agent-harness-handbook/setup/SETUP_en.html) for the full walkthrough.
