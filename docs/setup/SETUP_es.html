Guía de configuración del entorno del taller

Complete la instalación antes de que comience el taller — el objetivo es estar listo para comenzar directamente con la práctica cuando inicie la sesión, sin necesidad de configuración adicional del entorno.

Flujo de configuración

1. Actualizaciones del sistema operativo
   └─ Windows: winget upgrade --all
   └─ macOS:   brew update && brew upgrade
   └─ Linux:   apt update && apt upgrade

2. Herramientas fundamentales
   └─ Windows: PowerShell 7+, Windows Terminal, Git (+ Git Bash)
   └─ macOS / Linux: curl, git

3. Entornos de ejecución
   └─ bun  (entorno de ejecución y gestor de paquetes predeterminado)
   └─ python3
   └─ uv   (gestor de paquetes de Python)

4. Herramientas de CLI
   └─ gh  (GitHub CLI)
   └─ claude  (Claude Code CLI)
   └─ agy  (Antigravity CLI)

5. Aplicaciones de escritorio
   └─ Google Chrome
   └─ Claude aplicación de escritorio
   └─ Antigravity aplicación de escritorio
   └─ Mark  (visor de Markdown)

6. Verificación final ✅
   └─ bun setup-common.ts

Paso 1 — Complete la lista de verificación

Antes de ejecutar el script, lea y complete primero la Lista de verificación de preinstalación.

Elementos clave a confirmar

  • Suscripción activa a Claude Pro/Max y Gemini Advanced (un plan de suscripción, no una clave API)
  • Una cuenta de GitHub creada, lista para gh auth login
  • Al menos 5 GB de espacio libre en disco y privilegios de administrador/sudo confirmados

Paso 2 — Ejecute el script específico del sistema operativo

Abra una terminal con privilegios de administrador / sudo y ejecute el script para su sistema operativo.

macOS

bash setup-mac.sh
# Opcional: también instalar WezTerm (terminal con aceleración GPU)
bash setup-mac.sh --wezterm
# Opcional: también instalar Docker Desktop
bash setup-mac.sh --docker
# Ambos:
bash setup-mac.sh --wezterm --docker

Linux (Ubuntu / Debian)

bash setup-linux.sh
# Opcional: también instalar WezTerm
bash setup-linux.sh --wezterm
# Opcional: también instalar Docker
bash setup-linux.sh --docker
# Ambos:
bash setup-linux.sh --wezterm --docker

Windows

Ejecute PowerShell como administrador, luego ingrese el comando a continuación.

# Ejecución predeterminada (el script configura la política de ejecución automáticamente)
.\setup-windows.ps1

# Opciones:
.\setup-windows.ps1 -WSL2             # También instalar WSL2 (requiere reinicio)
.\setup-windows.ps1 -WezTerm          # También instalar WezTerm
.\setup-windows.ps1 -Docker           # También instalar Docker Desktop
.\setup-windows.ps1 -Force            # Reinstalar todas las herramientas, incluso las ya instaladas
.\setup-windows.ps1 -WSL2 -WezTerm -Docker  # Instalar todos los complementos opcionales
Después de ejecutar: cierre y vuelva a abrir su terminal para aplicar los cambios en PATH.

Solución de problemas

bun: command not found después de la instalación

Reinicie su terminal. En Windows, bun se registra automáticamente en las variables de entorno del usuario. macOS/Linux:

export PATH="$HOME/.bun/bin:$PATH"

claude: command not found después de bun install -g

El script reintenta automáticamente con un respaldo a npm si bun falla. Si el problema persiste, verifique la ruta con bun pm ls -g y agréguela a su PATH.

agy: command not found después de la instalación

El instalador de Antigravity CLI coloca el binario en ~/.local/bin o /usr/local/bin. Ejecute source ~/.bashrc o reinicie su terminal.

Windows: "running scripts is disabled on this system"

El script configura esto automáticamente como RemoteSigned. Para cambiarlo manualmente:

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
Windows: ejecución sin privilegios de administrador — el script muestra una advertencia pero continúa. Algunas instalaciones, como winget, pueden fallar, por lo que se recomienda volver a ejecutar PowerShell como administrador.

Verificación de registros de instalación

Los registros de ejecución del script de Windows se guardan automáticamente en %USERPROFILE%\workshop-setup-logs\.

Ejecute bun setup-common.ts, y una vez que cada elemento muestre ✅, el entorno del taller está listo.
