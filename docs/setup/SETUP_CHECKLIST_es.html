Lista de verificación de preinstalación del taller

Complete esta lista de verificación antes de ejecutar el script de instalación. Los elementos a continuación no pueden automatizarse y requieren acción manual.

1. Verificar suscripción (Prioridad máxima)

Las herramientas utilizadas en las sesiones prácticas del taller requieren una suscripción válida.

HerramientaPlan requerido
Claude Code CLI (claude)Claude Pro o Max
Claude Desktop App de escritorioClaude Pro o superior
Antigravity CLI (agy)Gemini Advanced
Antigravity App de escritorioGemini Advanced
Sobre las claves API: Las claves API solo son necesarias para integraciones fuera de su plan de suscripción. Las sesiones prácticas del taller están completamente cubiertas por el modelo de suscripción, por lo que solo emita una clave API si es verdaderamente necesario.

2. Preparación de cuentas

  • Cuenta de Google — necesaria para usar Antigravity / Gemini Advanced
  • Cuenta de GitHub — necesaria para gh auth login y ejercicios de PR
  • Si no tiene una, regístrese con anticipación en github.com/signup, siguiendo las instrucciones de registro en la sección de preparación de la práctica del Capítulo 4 §2-A

3. Requisitos del sistema

  • Sistema operativo: Windows 11 (Intel) / macOS Sequoia 15 o posterior en Apple Silicon (serie M) / Ubuntu 24.04 o posterior
  • Espacio libre en disco: 5 GB o más
  • Privilegios de administrador / sudo
  • Windows: Inicio → buscar "PowerShell" → clic derecho → "Ejecutar como administrador" (o Win + X → "Terminal (Admin)"), luego haga clic en "Sí" en el cuadro de confirmación de UAC
  • macOS / Linux: anteponga sudo al comando
  • Conexión a internet estable (tamaño total de descarga aprox. 1–2 GB)

4. Configuración de usuario de Git

Después de instalar git, registre su información de usuario con los comandos a continuación.

git config --global user.name  "Jane Doe"
git config --global user.email "you@example.com"
  • git config --global user.name configurado
  • git config --global user.email configurado

5. Autenticación en GitHub

gh auth login

Siga las indicaciones para completar la autenticación en su navegador.

  • Confirme que se muestra "Logged in" al ejecutar gh auth status

6. Configuración del entorno del proyecto (después de clonar el repositorio)

Al usar las variantes co-develop o co-consult:

cp .env.sample .env
# Abra el archivo .env y complete los valores requeridos
  • Creado .env a partir de .env.sample
  • Ingresadas las claves API / valores de configuración requeridos

Proyectos Python de co-develop — use uv (obligatorio):

uv sync          # Instalar dependencias basadas en pyproject.toml
# O, si usa requirements.txt:
uv pip install -r requirements.txt
  • Confirmado que uv está instalado y disponible (uv --version)
  • Dependencias de Python instaladas mediante uv
Docker es opcional. Instálelo solo si el facilitador se lo indica específicamente. Agregue la opción --docker en macOS/Linux o la opción -Docker en Windows al script de instalación.
  • (Opcional) Confirme que Docker está instalado y el daemon se está ejecutando

7. Verificación final del entorno (debe ejecutarse antes del taller)

Ejecute el siguiente comando desde dentro de la carpeta setup/ clonada. (Si aún no la has clonado, consulta el Paso 0 de la Guía de Instalación.)

bun setup-common.ts

Está listo una vez que cada elemento en la tabla de salida muestre ✅.

Para cualquier consulta, contacte al facilitador antes de que comience el taller.
