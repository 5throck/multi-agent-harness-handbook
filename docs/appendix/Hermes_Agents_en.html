Hermes Agents

A guide to using Hermes Agents as a platform within the workspace standards.

Scope

Follow the project’s shared rules and PM Gateway first; use Hermes as one execution platform.

Skills and settings

Manage project skills from a platform-neutral source of truth and keep Hermes-specific settings separate.

Safe operations

Start with least privilege. Put write and external-impact work behind approval and QA gates.

Verification and sync

Verify that platform-specific work follows the same governance, PR, and validation rules.

Keep platform-specific instructions narrow. Shared governance remains the source of truth.
