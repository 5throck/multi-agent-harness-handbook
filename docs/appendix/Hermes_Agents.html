Hermes Agents

Hermes Agents는 워크스페이스 표준에서 지원하는 AI 에이전트 플랫폼입니다.

적용 범위

프로젝트의 공통 규칙과 PM Gateway를 먼저 따르고, Hermes는 이를 실행하는 플랫폼 중 하나로 사용합니다.

스킬과 설정

프로젝트 스킬은 플랫폼 중립 SSOT를 기준으로 관리하고, Hermes 전용 설정은 다른 플랫폼 설정과 분리합니다.

안전한 운영

권한은 최소로 시작하고, 쓰기·외부 영향 작업은 승인과 QA 게이트를 거칩니다.

검증과 동기화

플랫폼별 결과가 동일한 거버넌스·PR·검증 규칙을 지키는지 확인합니다.
